# Contributing

Issues and pull requests are welcome, especially:

- results on other agents' transcripts (open-source trajectories preferred),
- questions that need several evidence items (synthesis), which the study does not yet cover,
- a non-Claude answerer or judge.

Setup and tests:

```bash
uv sync
uv run pytest -q
```

Rules for changes to results: keep `results.md` and `results.json` generated by `study/analyze.py`, never edited by
hand, and keep limitations in `REPORT.md` up to date. Please do not commit raw transcripts or anything derived from
private sessions.
